# Oneflow — Fintech

> Unified multi-currency treasury, instant FX converter, and programmable developer API.

## 🚀 Features
- Modern responsive design with Tailwind CSS
- Interactive UI components (calculators, modals, real-time filters)
- Fully accessible and mobile-optimized
- Fast loading static architecture, ready for Vercel deployment

## 🛠️ Tech Stack
- HTML5 / CSS3 / ES6+ JavaScript
- Tailwind CSS
- Lucide Icons & Google Fonts

## 📦 Deployment
Deployed instantly to Vercel and hosted on GitHub.
